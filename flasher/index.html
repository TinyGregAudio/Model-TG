Unofficial firmware

Model-TG is not made, supported or endorsed by Elektron. You install it at your own risk. Back up your projects and samples first. To go back, install the stock OS the same way.

1. Get the stock OS

Download Model:Cycles OS 1.13 (model-cycles_OS1.13.syx) from the Model:Cycles support page on elektron.se. It must be the unmodified file.

2. Build Model-TG from it

Your file never leaves your computer: this page patches it right here in your browser.

3. Install it

Save Model-TG.syx

  1. Connect the Cycles over USB and open Elektron Transfer.
  2. Check that Device Config > Transfer is set to CYC (every power-on starts there). Never install an OS while it is set to SMP.
  3. Send the file to the Cycles with Transfer, as you would an official OS update.
